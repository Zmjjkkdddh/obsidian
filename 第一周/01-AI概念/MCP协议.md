# MCP 协议（Model Context Protocol）

**MCP** 是 Anthropic 提出的**开放标准协议**，用于 LLM 与外部工具/数据源之间的标准化通信。

## 解决什么问题？

```
传统方式（N×N 集成噩梦）：
┌──────┐ ┌──────┐ ┌──────┐
│ App1 │ │ App2 │ │ App3 │    ← 每个应用为每个工具写适配器
└──┬───┘ └──┬───┘ └──┬───┘
   │ ───────┼─────────┼── 各自对接 ──
   ▼        ▼         ▼
┌──────┐ ┌──────┐ ┌──────┐
│  DB  │ │ API  │ │ File │
└──────┘ └──────┘ └──────┘

MCP 方式（标准化统一）：
┌─────────────────────────┐
│    AI 应用 / Agent       │
└───────────┬─────────────┘
            │  MCP 协议（统一标准）
  ┌─────────┼─────────┬─────────┐
  ▼         ▼         ▼         ▼
┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐
│数据库 │ │文件  │ │ API  │ │ 搜索 │
│Server│ │Server│ │Server│ │Server│
└──────┘ └──────┘ └──────┘ └──────┘
```

> 💡 类比：MCP 之于 AI 工具 = **USB-C 之于设备接口**

## 核心概念

| 概念 | 说明 |
|------|------|
| **MCP Server** | 暴露工具/数据的服务端（如文件系统 Server、数据库 Server） |
| **MCP Client** | AI 应用/Agent，通过协议调用 Server |
| **Tools** | Server 提供的可调用功能（搜索、读写、API 请求） |
| **Resources** | Server 暴露的数据（文件内容、数据库记录） |
| **Prompts** | Server 预置的提示词模板 |

## 架构

```
┌─────────────┐         ┌─────────────────────┐
│  MCP Client  │ ◄─────► │     MCP Server      │
│  (Claude,    │  JSON-  │  (文件/数据库/API…)   │
│   Codex...)  │  RPC    │                     │
└─────────────┘         └─────────────────────┘
   本地/HTTP/SSE 传输      本地进程 或 远程服务
```

## 优势

- **标准化**：一次开发，所有兼容 MCP 的 AI 应用通用
- **安全**：权限由用户控制，Server 可以跑在本地
- **生态**：社区不断贡献新的 Server（GitHub、Slack、数据库…）
