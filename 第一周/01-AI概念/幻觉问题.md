# 幻觉（Hallucination）

**幻觉**指 LLM 生成的内容**看似合理但实际是编造的、与事实不符**。

## 根本原因

```
LLM 本质 = 概率预测下一个最可能的 Token
        ≠ 检索事实数据库
        ≠ 知道什么是"真"什么是"假"
```

| 原因 | 说明 |
|------|------|
| 统计本质 | 只做概率预测，不做事实校验 |
| 概率采样 | temperature 引入随机性，可能"走偏" |
| 知识截止 | 训练数据截止后的事情不知道，被迫"编" |
| 长尾稀疏 | 罕见知识训练信号不足，容易混淆 |
| 过度泛化 | 不同语境的概念错误拼接 |

## 常见幻觉类型

| 类型 | 示例 |
|------|------|
| 事实错误 | "李白是宋朝人" |
| 编造引用 | 虚构不存在的论文、法条、书名 |
| 数字错误 | 日期、统计数据出错 |
| 逻辑矛盾 | 同一回答前后不一致 |

## 降低幻觉的方法

| 方法 | 原理 |
|------|------|
| **RAG** | 先检索真实文档，基于证据回答 |
| 降低 temperature | 减少随机性，减少"走偏" |
| 精确 Prompt | 约束范围，明确说"不知道就说不知道" |
| 引用来源 | 要求标注出处，便于人工复核 |
| Grounding | 搜索引擎接入，实时校验事实 |
