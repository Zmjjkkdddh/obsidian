# Agent 智能体

**Agent** 是让 LLM 从"聊天机器人"升级为"能自主行动的数字助理"的框架。

## 核心架构

```
┌──────────┐   思考    ┌──────────┐   执行     ┌──────────────┐
│   LLM    │ ───────→ │  Agent   │ ───────→  │   工具调用     │
│  (大脑)   │ ←─────── │  框架    │ ←───────  │   (手脚)      │
└──────────┘   观察    └──────────┘   结果    └──────┬───────┘
                                                    │
                                         ┌──────────┼──────────┐
                                         │ 搜索 │ 代码执行│ API │
                                         └────────────────────┘
```

## 核心循环：ReAct 模式

```
思考 → 行动 → 观察 → 思考 → 行动 → 观察 → ...
```

每一步：模型先思考该做什么，再调用工具执行，观察结果后决定下一步。

## Agent 的关键组件

| 组件 | 作用 |
|------|------|
| **LLM** | 大脑——推理和决策 |
| **工具 (Tools)** | 手脚——搜索、计算、代码执行、API 调用 |
| **记忆 (Memory)** | 短期（对话历史）+ 长期（外部存储） |
| **规划 (Planning)** | 任务拆解、子目标管理 |
| **MCP 协议** | 与工具的标准化通信接口 |

## 应用场景

- 自动化客服：查知识库 + 操作后台系统
- 代码开发助手：读写文件 + 执行命令 + 搜索文档
- 数据分析：写 SQL + 画图表 + 写报告
- 个人助理：查日历 + 发邮件 + 订机票
