# LLM 大语言模型

**LLM**（Large Language Model）是基于深度学习的 AI 模型，核心能力是**理解和生成人类语言**。

## 核心特征

| 特征 | 说明 |
|------|------|
| 训练数据 | 海量文本（书籍、网页、代码、论文），TB 级别 |
| 参数规模 | 数十亿到数万亿个参数 |
| 核心能力 | 文本生成、翻译、摘要、代码编写、推理、对话 |
| 工作原理 | Transformer 架构，"预测下一个词"学习语言规律 |

> 💡 LLM 像一个读过整个互联网的学霸——不是真正"理解"世界，而是通过海量文本学会了极其精准的语言模式匹配。
