# 上下文窗口（Context Window）

**上下文窗口**是 LLM 在一次对话中能"看到"和"记住"的**最大 Token 总量**。

```
┌──────────────────────────────────────────────┐
│            上下文窗口 (Context Window)          │
│                                              │
│  [系统提示] [对话历史] [用户输入] → [模型回复]    │
│                                              │
│  ←── 所有内容必须在窗口内 ──→                   │
│  超出窗口 → 被遗忘（截断或压缩）                  │
└──────────────────────────────────────────────┘
```

## 各模型上下文窗口

| 模型 | 窗口大小 | 相当于 |
|------|---------|--------|
| GPT-3.5 | 4K / 16K | 短文章 |
| GPT-4 | 8K / 32K / 128K | 中长篇 |
| Claude 3 | 200K | 一本《三体》 |
| Gemini 1.5 Pro | 1M ~ 2M | 多本书 + 视频 |

## 实际影响

- 窗口不够 → 长对话中模型"忘记"前面的内容
- 窗口太大 → 注意力稀释，关键信息可能被淹没
- **"大海捞针"测试**：在长文本中藏一条信息，测试模型能否找到——衡量上下文利用效率

## 扩展技术

- **RAG**：不把全部文档塞进窗口，先检索相关片段再回答
- **上下文压缩**：自动摘要历史对话，节省窗口空间
- **KV Cache 优化**：底层加速长上下文的推理
