# 向量数据库与 Embedding

## Embedding（嵌入）

将文本、图像等非结构化数据转化为**固定长度的向量（数字列表）**，捕获语义信息。

```
"今天天气真好" ──[Embedding 模型]──→ [0.023, -0.451, 0.892, ..., 0.134]
                                            ↑
                                    1536 维的浮点数向量
```

### 语义空间

语义相近 → 向量空间中也靠近：

```
"猫"  → [0.10, 0.80, 0.30, ...]   ┐
"猫咪" → [0.11, 0.79, 0.31, ...]   ├─ 距离近！
"汽车" → [-0.5, -0.2, 0.70, ...]   ┘  距离远
```

### Embedding 模型

| 模型 | 维度 | 特点 |
|------|------|------|
| OpenAI `text-embedding-3-small` | 1536 | 性价比高 |
| OpenAI `text-embedding-3-large` | 3072 | 精度最高 |
| BGE-M3 (BAAI) | 1024 | 开源，中英多语言 |
| Cohere Embed | 4096 | 多语言，压缩友好 |

## 向量数据库（Vector Database）

专门存储和检索**向量嵌入**的数据库——RAG 的检索引擎。

### 核心能力

- **近似最近邻搜索（ANN）**：在海量向量中快速找到最相似的
- **相似度度量**：余弦相似度、欧氏距离、点积
- **元数据过滤**：向量 + 结构化条件组合查询

### 主流向量数据库

| 数据库 | 特点 | 适合场景 |
|--------|------|---------|
| **Chroma** | 轻量开源，Python 原生 | 原型开发、小项目 |
| **Pinecone** | 全托管云服务 | 生产环境、免运维 |
| **Milvus** | 国产开源，分布式 | 大规模、高性能 |
| **Qdrant** | Rust 编写，高性能 | 对延迟敏感的场景 |
| **Weaviate** | 开源 + 云，功能丰富 | 需要混合搜索 |

## RAG 中的流程

```
原始文档
  → 切分成 Chunk（段落/语义块）
    → Embedding 模型转为向量
      → 存入向量数据库
        → 用户查询 → 同样转向量 → ANN 检索 → 返回最相关片段
```
