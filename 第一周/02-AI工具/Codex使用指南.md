# Codex 使用指南

OpenAI 推出的命令行 AI Agent，对标 Claude Code。

## 核心特点

| 特性 | 说明 |
|------|------|
| **终端原生** | 直接在终端中交互，类似 Claude Code |
| **文件操作** | 读写、搜索、编辑项目文件 |
| **Shell 集成** | 执行命令、管理进程 |
| **Git 感知** | 理解代码仓库上下文 |
| **多模型** | 可切换 GPT-4o / o4-mini 等 |

## 与 Claude Code 的主要区别

| 维度 | Codex | Claude Code |
|------|-------|-------------|
| 底层模型 | GPT-4o / o4-mini | Claude 3.5 / Opus 4 |
| 上下文 | 128K | 200K |
| MCP | 支持 | 原生深度支持 |
| 代码风格 | 直接简洁 | 详细注释 |
| 开源 | ✅ 开源 | ❌ 闭源 |

## 使用场景

- 代码审查和重构
- 自动化脚本编写
- 项目文档生成
- Bug 修复和调试
