# Claude 使用指南

Anthropic 推出的 AI 助手，擅长长文本处理、代码生成和深度推理。

## 版本与模型

| 模型 | 定位 | 上下文窗口 |
|------|------|-----------|
| Claude 3.5 Sonnet | 主力，速度与能力平衡 | 200K |
| Claude 3.5 Haiku | 最快最便宜 | 200K |
| Claude Opus 4 | 最强推理 | 200K |

## 核心优势

| 能力 | 说明 |
|------|------|
| **超长上下文** | 200K tokens，可一次读完一本书 |
| **代码能力** | SWE-bench 等基准领先 |
| **工具使用** | 原生支持 MCP 协议、函数调用 |
| **Artifacts** | 直接生成可交互的前端页面 |
| **安全性** | Constitutional AI，对齐做得更好 |

## Claude vs Claude Code：不是同一个东西

很多人混淆这两个名字，其实它们是**两层不同的产品**：

```
┌─────────────────────────────────────────────┐
│              Claude（模型/大脑）               │
│  Anthropic 的大语言模型，负责"思考"            │
│  不管你在哪里用它——网页、API、Claude Code      │
│  背后都是同一个模型在干活                       │
└─────────────────────┬───────────────────────┘
                      │ 模型能力被不同方式调用
    ┌─────────┬───────┼─────────┬─────────┐
    ▼         ▼       ▼         ▼         ▼
┌───────┐ ┌───────┐ ┌───────┐ ┌───────┐ ┌───────┐
│claude │ │  API  │ │Claude │ │MCP    │ │第三方的│
│  .ai  │ │       │ │ Code  │ │Server │ │ 集成   │
│ 网页   │ │ 编程   │ │ 终端   │ │ 工具   │ │       │
└───────┘ └───────┘ └───────┘ └───────┘ └───────┘
```

| | **Claude（模型）** | **Claude Code（工具）** |
|------|-------------------|------------------------|
| **是什么** | 大语言模型（AI 大脑） | CLI 命令行工具（Agent 外壳） |
| **类比** | 发动机 | 装了发动机的车 |
| **能干什么** | 理解语言、推理、生成文本 | 在此基础上：读写你的文件、执行命令、用 Git、连 MCP |
| **怎么用** | 网页/A PI/第三方集成 | 终端里敲 `claude` 命令 |
| **和你电脑的关系** | 默认碰不到你的文件 | 直接操作你的项目目录 |
| **谁在思考** | Claude 模型 | Claude 模型（同上一个大脑） |

### 一句话总结

> **Claude 是大脑，Claude Code 是给这个大脑装了手脚、接入了你的开发环境。**

### 各形式对比

| 使用方式 | 适用场景 | 能碰文件？ | 能跑命令？ | 适合谁 |
|------|---------|-----------|-----------|--------|
| **claude.ai** | 日常聊天、写文档、分析 | ❌ | ❌ | 所有人 |
| **Claude Code** | 写代码、改项目、自动化 | ✅ | ✅ | 开发者 |
| **API** | 集成到自己应用里 | ❌（除非你自己写） | ❌ | 开发者 |
| **MCP 生态** | 扩展工具能力 | ✅（通过 Server） | ✅（通过 Server） | 进阶用户 |

> 📌 **你正在用的就是 Claude Code**——所以我能直接读写你的 Obsidian 文件、执行命令。如果只是在 claude.ai 网页版对话，我是碰不到你本地文件的。

## 实用技巧

- **长文档处理**：先让它列出大纲，再逐段深入
- **代码生成**：描述清楚输入/输出/边界条件
- **结构化输出**：指定 JSON/YAML 格式
- **引用来源**：让它标注信息出处，便于验证
