# Claude 使用指南

Anthropic 推出的 AI 助手，擅长长文本处理、代码生成和深度推理。

## 版本与模型

| 模型 | 定位 | 上下文窗口 |
|------|------|-----------|
| Claude 3.5 Sonnet | 主力，速度与能力平衡 | 200K |
| Claude 3.5 Haiku | 最快最便宜 | 200K |
| Claude Opus 4 | 最强推理 | 200K |

## 核心优势

| 能力 | 说明 |
|------|------|
| **超长上下文** | 200K tokens，可一次读完一本书 |
| **代码能力** | SWE-bench 等基准领先 |
| **工具使用** | 原生支持 MCP 协议、函数调用 |
| **Artifacts** | 直接生成可交互的前端页面 |
| **安全性** | Constitutional AI，对齐做得更好 |

## 使用方式

| 方式 | 适合场景 |
|------|---------|
| claude.ai | 网页版，日常对话 |
| Claude Code | 命令行 Agent，适合开发者 |
| API | 集成到自己的应用 |
| MCP 生态 | 连接本地工具和数据源 |

## 与 Claude Code 配合

Claude Code 是命令行 Agent，能：
- 直接读写文件系统
- 执行 Shell 命令
- 用 Git 管理变更
- 连接 MCP Server 扩展能力

## 实用技巧

- **长文档处理**：先让它列出大纲，再逐段深入
- **代码生成**：描述清楚输入/输出/边界条件
- **结构化输出**：指定 JSON/YAML 格式
- **引用来源**：让它标注信息出处，便于验证
