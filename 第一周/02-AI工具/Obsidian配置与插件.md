# Obsidian 配置与插件

## 核心配置

| 配置项 | 路径 | 说明 |
|--------|------|------|
| 附件路径 | 设置 → 文件与链接 | 统一到固定目录 |
| 图片下载 | 设置 → 快捷键 | 绑定 `Ctrl+Shift+D` |
| 模板 | 设置 → 模板 | 定义笔记模板 |

## 推荐插件

| 插件 | 用途 |
|------|------|
| **Dataview** | 将笔记当数据库查询 |
| **Web Clipper** | 一键剪藏网页为 Markdown |
| **Marp Slides** | Markdown 转演示文稿 |
| **Excalidraw** | 手绘风格图表 |
| **Kanban** | 看板管理 |
| **Calendar** | 日历视图导航 |
| **Templater** | 高级模板引擎 |

## 与 AI 配合

```
Obsidian = IDE
LLM Agent = 程序员
笔记库 = 代码库
```

- AI 读写 Wiki 链接：`[[页面名]]`
- AI 维护 YAML frontmatter
- AI 更新交叉引用和索引
- Obsidian 图视图 → 可视化知识结构
