# Mac 安装 CC-Switch 详细步骤

> 你在 Windows 上已经在用，账号订阅都现成的。Mac 上只需安装客户端 + 登录。

---

## 第 1 步：下载 Mac 版客户端

用 Windows 打开 CC-Switch 官网（你注册账号的那个网站），找到**下载页面** → 选 **macOS 版** → 下载 `.dmg` 文件。

如果找不到网址，打开 Windows 上的 CC-Switch 客户端，一般在设置里有"官网"或"下载"入口。

下载完把 `.dmg` 拷到 Mac（U 盘 / 微信 / AirDrop）。

> ⚠️ Mac 目前没外网，用 **U 盘** 最稳。

---

## 第 2 步：安装

Mac 上双击 `.dmg` 文件：

```
┌─────────────────────────────┐
│   CC-Switch                 │
│                             │
│   把 CC-Switch 图标         │
│   拖到 Applications 文件夹   │
│                             │
│   🟡 CC-Switch  →  📁 Apps │
└─────────────────────────────┘
```

然后在"启动台"（Launchpad）里就能看到 CC-Switch 图标了。

---

## 第 3 步：首次打开

1. 双击 CC-Switch 图标
2. 如果提示"无法打开，因为来自未认证的开发者"：

```
系统设置 → 隐私与安全性 → 往下滑 → 点击"仍要打开"
```

3. 登录你的账号（和 Windows 上用的是同一个）

---

## 第 4 步：连接

登录后主界面会显示节点列表。选择一个节点，点"连接"。

```
┌──────────────────────┐
│  🇭🇰 香港 01   ████   │
│  🇯🇵 日本 01   ███    │
│  🇺🇸 美国 01   ██     │
│  🇸🇬 新加坡 01 ████   │
│                      │
│  [ 一键连接 ]         │
└──────────────────────┘
```

连接成功后，Mac 菜单栏右上角会出现 CC-Switch 小图标——显示已连接。

---

## 第 5 步：验证

打开 Safari，访问 `https://www.google.com`，能打开就是成功了。

---

## 第 6 步：设为开机自动启动

CC-Switch → 偏好设置 → 勾选"开机启动"和"启动后自动连接"。

```
以后开机 → CC-Switch 自动启动 → 自动连上 → 不用管
```

---

## 完全没外网怎么办？

如果 Mac 连 CC-Switch 官网都打不开，有两条路：

### 方案 A：用 Windows 下载后拷过去

```
Windows（有网）→ 下载 CC-Switch Mac 版 .dmg → U 盘 → Mac → 安装
```

### 方案 B：临时共享 Windows 代理

让 Mac 先通过 Windows 上网，下好 CC-Switch 后再换回来。**这个只需要改 Mac 上一个设置**：

1. Windows 上查看局域网 IP：

```powershell
ipconfig
# 找"无线局域网适配器"下的 IPv4 地址，类似 192.168.1.xxx
```

2. Mac 上：**系统设置 → 网络 → Wi-Fi → 详细信息 → 代理 → SOCKS 代理**

| 服务器 | 端口 |
|--------|------|
| `192.168.1.xxx`（Windows IP） | `1081` |

3. 勾选 SOCKS 代理，点"好"。Mac 就能通过 Windows 上网了。

4. 用 Safari 打开 CC-Switch 官网 → 下载 Mac 版 → 安装 → 登录 → 切到自己线路 → 断开 Windows 代理。
